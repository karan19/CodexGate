GET STARTED

A local app. A deliberate launch.

  1. Download the Apple Silicon DMG, drag CodexGate to Applications, eject the disk image, and open the installed copy. The app includes its runtime. Older macOS compatibility is still unverified.
  2. Alternatively, install with Homebrew using the command above. No Git clone or build tools are needed.
  3. Open CodexGate from Applications.
  4. Save folder rules. Finish active work and fully quit Codex, then select Start protected Codex.
For developers: build from source

Clone the repository, then run the installer from that folder. Requires Xcode Command Line Tools and Homebrew Python.

git clone https://github.com/karan19/CodexGate.git
cd CodexGate
/opt/homebrew/bin/python3 scripts/install_menu_bar.py

Experimental v0.1.0, not Developer ID signed or notarized. If macOS blocks it, review Apple’s guidance and approve only a copy you trust via Privacy & Security → Open Anyway, when available. Never disable Gatekeeper globally or interrupt active chats to try a launch.

KNOW THE BOUNDARY

Clear scope. No blanket promises.

Normal Codex launches remain unrestricted by this tool. Temporary grants use a local read/list service; they do not unlock direct filesystem access. Runtime/profile exceptions remain. Sandbox detection alone does not establish exact rules.

Computer Use and browser interactions are outside this filesystem-control guarantee. Automatic access requests and exact per-instance policy attribution are still planned.
