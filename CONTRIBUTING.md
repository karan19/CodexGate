# Contributing

Use synthetic files and temporary directories. Never commit grants, credentials, personal paths, browser profiles, launch logs, or real mailbox data.

Describe the behavior changed and the tests run. Changes to authentication, path opening, sandbox rules, deployment, or grant expiry must include meaningful regression coverage. Keep saved configuration separate from observed live protection in every UI label.

Build the native app on macOS and verify the popover in light/dark mode. Do not restart someone’s Codex instance automatically.

Use GitHub issues and pull requests for collaboration.
