# CodexGate v0.1.0 — experimental preview

Unofficial macOS menu-bar companion for Codex folder access. Apple Silicon only. Ad-hoc signed, not Developer ID signed or notarized; macOS may block downloaded copies.

Drag to Applications and eject the DMG before launching. Quit the old Folder Access controller first to avoid a port conflict. Do not quit Codex until active tasks finish.

Includes the Python service runtime and native authentication helper. Supports saved next-launch folder rules and independent ten-minute broker read/list grants, extension and revocation.

Sandbox presence does not verify exact policy. Temporary grants do not unlock direct access. Computer Use/browser channels and unrestricted same-user programs are outside the filesystem guarantee. Automatic agent request integration is not implemented. Clean-machine/older-macOS compatibility and exact policy attribution remain unverified.

Native builds, broker/API/policy tests and packaged-service smoke tests passed. DMG integrity checked. User confirmed installed-app operation; exhaustive live boundary coverage is not claimed.
